ShortsUploader

A private, single-user upload tool for short videos.

What it is

ShortsUploader is a Windows console application that its developer runs on their own computer. It uploads the developer's own original short videos to the developer's own YouTube channel, Facebook Page, Instagram account and TikTok account. It is not a public service: it has no sign-up, no hosted interface and no users other than its developer.

How it works

The developer places a finished video file and a small text file containing the title and description into a local folder. On a schedule, the application uploads each video, records the result in a local log file, and moves the files to a "posted" or "failed" folder.

Use of YouTube API Services

ShortsUploader uses YouTube API Services (the YouTube Data API v3) to upload videos to the developer's own channel. It asks for the minimum access it needs: permission to upload videos, and read-only access used once to confirm which channel was authorized. It does not read, display, analyze or store any other YouTube data.

By using ShortsUploader, the user agrees to be bound by the YouTube Terms of Service. See our Privacy Policy for what data is handled and how to revoke access, and our Terms of Service.

Instagram and TikTok

Videos are posted to the developer's own Instagram professional account through the Instagram Graph API, and sent to the developer's own TikTok account through the TikTok Content Posting API. The developer signs in with TikTok Login Kit and grants the user.info.basic and video.upload permissions (and video.publish when direct posting is turned on). Each video is uploaded with the caption the developer wrote; nothing else is read from or written to TikTok.
