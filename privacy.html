Privacy Policy

Last updated: October 23, 2026

ShortsUploader is a private Windows console application used only by its developer to upload the developer's own videos to the developer's own YouTube channel, Facebook Page, Instagram account and TikTok account. This policy explains what data the application accesses, stores and shares.

YouTube API Services

ShortsUploader uses YouTube API Services to upload videos. By using ShortsUploader, the user agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (https://policies.google.com/privacy).

Information the application accesses

With the user's authorization through Google's OAuth 2.0 consent screen, the application:

  • uploads video files, titles, descriptions and tags that the user supplies to the user's own YouTube channel (scope youtube.upload);
  • reads the name and ID of the authorized channel once, to confirm the correct channel was selected (scope youtube.readonly).

It does not access any other YouTube data. It does not access data about viewers, subscribers, comments, or any other YouTube user.

Information the application stores

  • OAuth tokens issued by Google and TikTok, and the Meta Page access token, stored in files on the user's own computer so the user does not have to sign in on every run.
  • A local log file listing each uploaded file name, the date and time, and the video or post ID returned by each platform.

This data never leaves the user's computer. ShortsUploader has no server, no database, no analytics and no advertising. It does not use cookies or any similar tracking technology, and it does not place or read information on any device other than the files described above.

How information is used and shared

Stored tokens are used only to send the user's upload requests to the platform that issued them. No information is sold, transferred or disclosed to any third party. Video content and its metadata are sent only to the platforms the user chose to publish to (YouTube, Facebook, Instagram and TikTok).

Revoking access and deleting data

  • Revoke access: remove ShortsUploader at any time from the Google security settings page at https://myaccount.google.com/permissions. The application can no longer act on the account once access is revoked.
  • Revoke TikTok access: in the TikTok app open Settings and privacy → Security → Manage app permissions and remove ShortsUploader.
  • Revoke Facebook and Instagram access: remove ShortsUploader under Facebook Settings → Business integrations.
  • Delete stored data: delete the youtube-token and tiktok-token folders, the tokens in the configuration file, and the upload-log.txt file from the application's folder. This removes all data the application has stored. Nothing is held anywhere else.

Stored authorization tokens are deleted when access is revoked or when the token folder is removed. The application stores no other YouTube API data, so there is nothing further to refresh or delete.

Facebook and Instagram

The application also posts the same videos to the developer's own Facebook Page and to the Instagram professional account linked to that Page, using a Page access token stored in a local configuration file (permissions pages_manage_posts, instagram_basic and instagram_content_publish). It reads only the IDs needed to publish and the link of the published post. It reads no Facebook or Instagram user data.

TikTok

The application sends the same videos to the developer's own TikTok account using the TikTok Content Posting API. The developer signs in through TikTok Login Kit and grants these permissions:

  • user.info.basic: reads the account's display name and open ID once, to confirm which account was authorized;
  • video.upload: uploads the video to the account's TikTok inbox as a draft, which the account owner finishes and posts in the TikTok app;
  • video.publish (only when direct posting is turned on): posts the video to the account with the caption and privacy level the account owner chose.

The TikTok access and refresh tokens are stored only on the user's own computer. The application does not read videos, followers, comments, messages or any other TikTok data, and shares nothing with third parties. TikTok's handling of data is described in the TikTok Privacy Policy.

Children's privacy

ShortsUploader is a developer tool. It is not directed at children and collects no information from anyone, including children.
